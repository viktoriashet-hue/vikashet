01 Основы

Что такое Claude Code и зачем он эксперту

Claude Code — это ИИ-агент от Anthropic, который работает прямо с файлами на вашем компьютере. Обычный чат выдаёт текст, а дальше вы копируете, вставляете и собираете всё руками. Claude Code сам создаёт файлы, правит их, запускает команды и доводит задачу до конца.

Для эксперта или маркетолога это значит простую вещь: задачи, за которые раньше платили разработчику, теперь можно поставить обычным языком.

  • собрать лендинг под мастер-группу и опубликовать его;
  • сделать Telegram-бота с лид-магнитом;
  • оформить серию каруселей по готовому тексту;
  • разобрать выгрузку заявок и найти, какие посты приносят клиентов.
ГлавноеПрограммировать не нужно. Достаточно открыть терминал и вставить команду. Ставить задачи можно на русском.

02 Если вы в России

Честно и по делу

Коротко: официально Claude Code в России недоступен, ни в терминале, ни в веб-версии. Anthropic работает только в странах из этого списка, и России там нет.

В Telegram можно встретить советы вроде «купите иностранную сим-карту» или «зайдите через GitHub». Я их не рекомендую. Это прямой обход правил сервиса: аккаунты за такое блокируют, часто вместе с уже оплаченной подпиской, и вернуть деньги потом сложно. Если вы строите на этом инструменте работу с клиентами, рисковать ей из-за одной сим-карты не стоит.

Хорошая новостьСама логика работы — агент, который сам создаёт файлы, собирает сайты и ботов по задаче на русском — доступна и в России. Ниже инструменты, которыми можно пользоваться легально.

Вариант 1. OpenCode — самый близкий аналог

OpenCode — бесплатный агент с открытым кодом. Работает в терминале почти так же, как Claude Code: читает проект, правит файлы, запускает команды. Сама программа бесплатная, платите только за модель, которую к ней подключите.

Mac / Linux
curl -fsSL https://opencode.ai/install | bash
Windows (или любая система с Node.js)
npm install -g opencode-ai

02 Если вы в России

Подключаем модель к OpenCode

Дальше перейдите в папку проекта, запустите opencode и введите /connect, чтобы подключить модель. Из России доступны, например:

  • российские облака с оплатой в рублях — например, Evolution Foundation Models от Cloud.ru, у них есть готовая инструкция именно для OpenCode;
  • DeepSeek — в /connect выбираете deepseek и вставляете API-ключ (официальная инструкция);
  • локальные модели через Ollama или LM Studio: бесплатно, но нужен мощный компьютер.

Всё, что дальше сказано про CLAUDE.md, работает и здесь. Команда /init создаёт файл AGENTS.md — это та же «память проекта»: туда пишете аудиторию, стиль и ссылки. Клавиша Tab включает режим планирования, где агент сначала показывает план и только потом делает.

Вариант 2. Российские ИИ-ассистенты

GigaCode

От Сбера. Работает с агентным режимом в VS Code и JetBrains, понимает задачи на русском.

SourceCraft

От Яндекса. Ассистент в VS Code и JetBrains: чат, генерация кода, публикация проекта.

Koda

Агент с консольной версией и плагином для редактора, умеет подключать разные модели.

Эти инструменты рассчитаны прежде всего на разработчиков и работают внутри редактора кода, а не в отдельном окне. Для лендинга или простого бота их хватит, но порог входа чуть выше, чем у OpenCode.

Мой советНачните с OpenCode и российского облака. Установка займёт 10 минут, а привычки, которые вы здесь наработаете (CLAUDE.md/AGENTS.md, одна задача на один диалог, скиллы), пригодятся в любом агенте, включая Claude Code, если окажетесь в стране, где он доступен.

03 Китайские ИИ

Китайские ИИ, которые умеют то же, что Claude Code

Китайские модели за последний год сильно подтянулись в программировании. Для задач эксперта и маркетолога — лендинг, бот, скрипт для таблицы, разбор выгрузки — их уровня обычно хватает. При этом они в разы дешевле, а сайты и API открываются из России напрямую.

Схема та же, что у Claude Code: вы ставите задачу обычным языком, агент сам создаёт файлы, правит их и запускает команды. Отличается только «мозг» внутри.

Как пользоваться: общая схема для всех

  1. Зарегистрируйтесь на сайте модели и получите API-ключ или оформите подписку (Coding Plan).
  2. Откройте агента: у Qwen и Kimi есть свои, остальные модели удобно подключать к OpenCode через команду /connect.
  3. Перейдите в папку проекта и создайте «память проекта» командой /init. Запишите в файл аудиторию, стиль, ссылки и правило «отвечай на русском».
  4. Поставьте задачу конкретно: что сделать, для кого, какие блоки, куда ведёт кнопка.
  5. Для больших задач сначала попросите план, проверьте его, потом дайте команду делать.

Инструменты: DeepSeek и Qwen Code

DeepSeek

DeepSeek · модели V4 и V4 Flash

Как пользоватьсяСвоего агента нет, модель подключается к OpenCode: /connect → deepseek → API-ключ из личного кабинета.
Для чегоЛендинги, скрипты, работа с большими текстами: модель держит в памяти до миллиона токенов, поэтому подходит для разбора длинных документов, выгрузок комментариев, транскрибаций.

Qwen Code

Alibaba · модели Qwen

Как пользоватьсяОтдельный агент в терминале, внешне и по логике очень похож на Claude Code. Сама программа бесплатная, модель подключается через подписку или API-ключ.
Для чегоДлинные многошаговые задачи: собрать проект из нескольких файлов, доработать бота, переделать сайт целиком.
РезультатОдин из сильнейших китайских вариантов для агентной работы, то есть для задач, где нужно много шагов подряд.
СтоимостьБесплатный вход через аккаунт Qwen закрыли в апреле 2026. Сейчас Coding Plan стоит около $50 в месяц, либо можно платить за использование через API.

04 Установка

Как установить Claude Code на Windows и Mac

Рекомендуемый способ — официальный установщик. Одна команда, и дальше Claude Code обновляется сам.

Terminal · macOS / Linux
curl -fsSL https://claude.ai/install.sh | bash
PowerShell · Windows
irm https://claude.ai/install.ps1 | iex
CMD · Windows
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
Как понять, где вы находитесьЕсли в начале строки написано PS C:\, это PowerShell. Если просто C:\, это CMD. Ошибка 'irm' is not recognized значит, что вы в CMD. Ошибка про && значит, что вы в PowerShell.

Для Windows ещё советую поставить Git for Windows: с ним Claude Code работает стабильнее, а позже пригодится для публикации сайтов на GitHub Pages.

Альтернативные способы

Homebrew (Mac)
brew install --cask claude-code
WinGet (Windows)
winget install Anthropic.ClaudeCode

При установке через Homebrew или WinGet автообновлений нет, обновлять придётся вручную (brew upgrade claude-code или winget upgrade Anthropic.ClaudeCode).

04 Установка

Без установки: веб-версия claude.ai/code

Если ставить ничего не хочется или компьютер рабочий и чужой, откройте claude.ai/code в браузере. Это тот же Claude Code, только работает он не на вашем компьютере, а в облаке Anthropic.

  • Что нужно: тот же платный аккаунт Claude (Pro, Max или Team) и аккаунт на GitHub. Файлы проекта хранятся в репозитории, туда же Claude сохраняет результат.
  • Как начать: войдите в аккаунт, подключите GitHub, выберите репозиторий или создайте новый и напишите задачу.
  • Удобно: задача продолжает выполняться, даже если вы закрыли ноутбук. Проверить результат можно с телефона, во вкладке Code приложения Claude.
Для кого это идеальный вариантДля лендингов и сайтов на GitHub Pages. Пишете задачу в браузере, Claude собирает сайт и сохраняет его в репозиторий, а GitHub сам публикует страницу. Терминал не нужен вообще.

Terminal

Если в ответ пришёл номер версии с припиской (Claude Code), всё установилось. Если что-то пошло не так, запустите диагностику:

05 Первый запуск

Первый запуск и вход в аккаунт

Создайте папку под проект, например my-landing, перейдите в неё и запустите Claude:

Terminal
cd my-landing
claude

При первом запуске откроется браузер: войдите в аккаунт Claude и подтвердите доступ. Больше вводить логин не придётся. Сменить аккаунт можно командой /login прямо внутри Claude Code.

Дальше просто пишите задачу. Например:

Промпт
Сделай одностраничный лендинг для психолога: оффер, 3 блока с болями,
программа консультации, отзывы, кнопка записи в Telegram. Тёмный стиль, мобильная версия.

Перед изменением файлов или запуском команд Claude может спросить разрешение. Режимы разрешений переключаются клавишами Shift + Tab: от «спрашивать всё» до автоматического режима, когда Claude сам решает рутинные шаги.

Мой советПервые пару недель работайте в режиме с подтверждениями и читайте, что Claude собирается сделать. Так вы быстрее поймёте логику агента и научитесь ставить задачи точнее.

06 Команды

Команды, которые нужны каждый день

claudeЗапустить Claude Code в текущей папке
claude -cПродолжить последний диалог в этой папке
claude -rВыбрать и продолжить один из прошлых диалогов
/initСоздать CLAUDE.md: Claude изучит проект и запишет главное
/clearОчистить диалог и начать новую задачу с чистого листа
/mcpПосмотреть и настроить подключённые сервисы
/helpСписок всех команд
/Показать доступные команды и скиллы
Shift + TabПереключить режим разрешений
/exitВыйти

Правило, которое экономит больше всего лимитов: одна задача — один диалог. Закончили лендинг — /clear, и только потом берите бота. Длинная переписка тратит больше токенов и сбивает фокус агента.

07 CLAUDE.md

CLAUDE.md — память проекта

CLAUDE.md — это обычный текстовый файл в папке проекта. Claude читает его в начале каждой сессии. Всё, что вы устали повторять, пишите туда.

Проще всего создать его командой /init, а потом дописать своё. Пример для эксперта:

CLAUDE.md
# Проект: лендинг мастер-группы
- Автор: психолог, аудитория — женщины 30–45, запрос на отношения
- Tone of voice: спокойно, без давления, без слов «трансформация» и «уникальный»
- Стиль: тёмный фон #0D0D14, акцент #C8A96E, шрифты Cormorant Garamond + Manrope
- Все кнопки ведут в Telegram: https://t.me/username
- Всегда делать мобильную версию и проверять её
- Отвечать мне на русском
Правило из практикиЕсли Claude дважды ошибся в одном и том же, это строчка в CLAUDE.md. Сам файл держите коротким, до 200 строк. Длинные инструкции лучше вынести в скиллы.

Кроме файла проекта есть личный CLAUDE.md, который действует во всех проектах. Он лежит в папке ~/.claude/. Туда стоит записать общее: «отвечай на русском», «я не программист, объясняй простыми словами».

08 Скиллы

Скиллы: как сделать свои инструкции по кнопке

Скилл — это сохранённая инструкция для задачи, которую вы делаете снова и снова. Один раз описали, как вы пишете посты, проверяете лендинг или оформляете карусель, и дальше вызываете это одной командой: /post, /landing-check, /carousel.

CLAUDE.mdСкилл
Когда загружаетсяВсегда, в начале каждой сессииТолько когда нужен
Что туда писатьПравила «всегда делай так»: аудитория, язык, стильПошаговые процессы и справочники: как писать пост, как проверять сайт
Как вызватьНикак, работает самКомандой /название или Claude подключает сам по описанию

Когда пора делать скилл: вы в третий раз вставляете в чат одну и ту же длинную инструкцию. Это готовый скилл.

Где лежат скиллы

Личный~/.claude/skills/название/SKILL.md — во всех ваших проектах на этом компьютере
Проектный.claude/skills/название/SKILL.md — только в этой папке проекта, передаётся вместе с ним

Бренд-гайд и стиль письма делайте личными скиллами, они нужны везде. Инструкции под конкретного клиента делайте проектными.

08 Скиллы

Способ 1. Попросить Claude сделать скилл

Самый простой путь для тех, кто не пишет код. Прямо в Claude Code напишите:

Промпт
Создай личный скилл post-threads. Он пишет пост для Threads по теме,
которую я передаю после команды. Правила: крючок в первой строке, до 500 символов,
без слов «трансформация» и «уникальный», в конце вопрос к аудитории.
Сделай 3 варианта на выбор.

Claude сам создаст папку и файл в нужном месте. Если в сессии был удачный процесс, можно сказать проще: «Сохрани то, что мы сейчас делали, как скилл».

Способ 2. Сделать вручную

  1. Создайте папку с названием скилла латиницей через дефис, например ~/.claude/skills/post-threads/.
  2. Положите в неё файл SKILL.md. Это обычный текстовый файл, его можно написать в любом редакторе.
  3. Перезапустите Claude Code и проверьте командой /skills, что скилл появился в списке.

08 Скиллы

Из чего состоит SKILL.md

Две части: шапка между линиями --- и сама инструкция.

~/.claude/skills/post-threads/SKILL.md
---
name: post-threads
description: Пишет посты для Threads в стиле автора. Используй, когда просят
  пост, ветку или текст для Threads.
argument-hint: [тема поста]
---

Напиши пост для Threads на тему: $ARGUMENTS

## Правила
- Первая строка — крючок: конкретная боль или цифра
- До 500 символов, короткие абзацы
- Без слов «трансформация», «уникальный», «волшебство»
- В конце вопрос к аудитории

## Формат ответа
3 варианта, между ними пустая строка. Перед каждым — одной фразой, на что он давит.

## Примеры моих постов
Смотри файл examples.md в папке скилла.

Теперь пишете /post-threads почему психологу не нужны охваты, и тема подставляется вместо $ARGUMENTS.

Главные поля шапки

nameНазвание, оно же команда: /post-threads
descriptionСамое важное поле. По нему Claude решает, когда подключить скилл сам
argument-hintПодсказка, что писать после команды
disable-model-invocationСкилл запускается только вашей командой. Ставьте для публикации сайтов и всего, что нельзя делать без спроса
context: forkСкилл работает в отдельном «помощнике» и возвращает только итог. Удобно для исследований, чтобы не засорять диалог

Как написать description, чтобы скилл срабатывал

  • Сначала что делает, потом когда использовать: «Пишет посты для Threads. Используй, когда просят пост или ветку».
  • Добавьте слова, которыми вы обычно формулируете задачу: «пост», «ветка», «тред», «текст для соцсетей».
  • Не делайте два скилла с похожими описаниями, иначе Claude будет путать их.

08 Скиллы

Дополнительные файлы и с каких скиллов начать

В папку скилла можно положить что угодно: примеры ваших лучших постов, бренд-гайд, шаблон лендинга, список болей аудитории. В SKILL.md просто укажите, когда их читать.

Структура
post-threads/
├── SKILL.md        ← инструкция (обязательно)
├── examples.md     ← 5–10 ваших лучших постов
└── audience.md     ← боли и формулировки клиентов
Секрет качества5–10 реальных примеров дают больше, чем страница правил. Claude перенимает ритм, длину фраз и ваши словечки.

Какие скиллы я советую эксперту завести первыми

Бренд-гайд

Цвета, шрифты, ссылки, tone of voice. Каждый новый сайт или визуал сразу получается в стиле.

Пост в вашем стиле

Правила, примеры и формат. Тема передаётся после команды.

Чеклист лендинга

SEO, мобильная версия, ссылки, кнопки — проверка перед публикацией.

Публикация сайта

Пошаговый деплой на GitHub Pages. Только ручной запуск.

Как проверить и улучшить скилл

  1. Проверяйте в новой сессии: в старой Claude и так помнит контекст, и скилл кажется лучше, чем он есть.
  2. Не сработал сам — допишите в description слова из вашего запроса. Или вызывайте командой.
  3. Результат не тот — не правьте в чате, а добавьте правило или пример в сам скилл. Так ошибка не повторится.
  4. Держите SKILL.md коротким, до 500 строк. Большие справочники выносите в отдельные файлы рядом.

Хорошая новость для тех, кто пользуется OpenCode и китайскими агентами: формат скиллов похож и там, так что ваши инструкции переносятся почти без правок.

09 MCP

MCP — подключение сервисов

MCP (Model Context Protocol) — это способ подключить Claude Code к внешним сервисам: Notion, GitHub, Google Drive, базам данных, браузеру. После подключения Claude сам берёт оттуда данные и выполняет действия.

Подключение онлайн-сервиса выглядит так:

Terminal
claude mcp add --transport http notion https://mcp.notion.com/mcp

После этого внутри Claude Code наберите /mcp: там видно статус подключения, и там же проходит вход в сервис.

--scope localПо умолчанию — сервис нужен только в этом проекте
--scope userВсе ваши проекты — Notion или GitHub, которыми пользуетесь везде
--scope projectПроект + команда — настройка сохраняется в файл и передаётся вместе с проектом
Не подключайте всё подрядХороший сигнал, что пора подключать сервис: вы в третий раз копируете данные из вкладки браузера в чат. Значит, этот сервис стоит подключить через MCP.

11 Кейсы

Кейсы: что психолог или эксперт может настроить в Claude Code

Ниже процессы, которые я настраиваю экспертам помогающих профессий. У каждого две цели: освободить время и получать заявки без ручной работы.

Воронка по кодовому слову

ПроцессПодписчик пишет слово в комментариях или боту, получает лид-магнит, проходит короткую анкету.
Что делает ClaudeСобирает Telegram-бота, сценарий, анкету и выгрузку заявок в таблицу.
ЭкономияНе нужно вручную отвечать каждому в директ и пересылать материалы.
ЗаявкиЗаявки приходят круглосуточно, уже с ответами анкеты: вы видите запрос до созвона. В моей практике такая связка дала около 200 целевых откликов с 4 постов у психолога.

Лид-магнит в виде теста или мини-гайда

ПроцессТест «Что мешает вам выстроить опору на себя» или чек-лист на отдельной странице.
Что делает ClaudeДелает страницу теста с результатами и кнопкой в Telegram, в вашем стиле и с мобильной версией.
ЭкономияНе нужен дизайнер и разработчик, правки занимают минуты.
ЗаявкиТест собирает контакты тёплой аудитории, которая уже узнала себя в результатах.

Лендинг под консультацию или группу

ПроцессСтраница с оффером, болями, программой, отзывами и кнопкой записи.
Что делает ClaudeСобирает страницу по вашему брифу и публикует её на GitHub Pages.
ЭкономияСтраница готова за вечер, без недели ожидания подрядчика.
ЗаявкиОдна понятная ссылка для шапки профиля, постов и рассылки.

Контент-завод в вашем стиле

ПроцессИз одной темы или эфира — серия постов, ветка для Threads, текст для карусели.
Что делает ClaudeРаботает по скиллу с вашими правилами и примерами лучших постов.
ЭкономияКонтент на неделю собирается за один подход, а не пишется каждый день с нуля.
ЗаявкиРегулярный контент под боли аудитории — то, что приводит людей в воронку.

Анализ комментариев и анкет

ПроцессВыгрузка комментариев, ответов анкеты и вопросов из директа.
Что делает ClaudeГруппирует боли и формулировки клиентов, предлагает темы постов и офферы.
ЭкономияНе нужно перечитывать сотни сообщений вручную.
ЗаявкиПосты говорят словами клиентов, поэтому чаще попадают в запрос и приводят заявки.

Запись и напоминания

ПроцессБот записи на консультацию: выбор времени, напоминание за день и за час.
Что делает ClaudeСобирает бота и связку с календарём или таблицей.
ЭкономияНет переписки «а когда вам удобно».
ЗаявкиМеньше пропущенных сессий и потерянных клиентов между «хочу» и «записалась».
Важно для психологовВ Claude и любые другие ИИ не загружайте записи сессий, имена клиентов и их истории. Для воронок и контента это и не нужно: работаете с темами, болями и формулировками без персональных данных.

Как ускориться

  1. Начните без терминала. Десктоп-приложение или веб-версия снимают всю возню с установкой. В терминал переходите, когда освоитесь.
  2. Пишите задачу по брифу: для кого, какая цель, какие блоки, куда ведёт кнопка, какой стиль. Один абзац брифа экономит пять кругов правок.
  3. Один раз заполните CLAUDE.md — аудитория, стиль, ссылки. Больше не объясняете это никогда.
  4. Сделайте скиллы на всё повторяющееся: пост, проверка лендинга, публикация сайта.
  5. Сначала план, потом работа. Попросите Claude показать план и поправьте его до того, как он начнёт делать.
  6. Одна задача — один диалог. Между задачами /clear: так и лимиты целее, и Claude меньше путается.
  7. Берите готовые шаблоны: удачный лендинг или бот становится основой для следующего. Второй проект собирается в разы быстрее первого.
  8. Давайте свои тексты и примеры, а не просите «придумай». Claude отлично оформляет и дорабатывает, но ваш голос лучше вас никто не знает.
  9. Не идите в одиночку. Самый быстрый путь — чтобы кто-то, кто уже прошёл эти грабли, настроил систему под ваши задачи.
